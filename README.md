# 🦅 Bercy Algorand — x402 + AC2

Cross-border FX payments on Algorand Mainnet via x402 + AC2.

## Features
- x402 payment gate — official @x402/hono SDK + goplausible facilitator
- AC2 human approval before every payment
- 20+ corridors: Africa, MENA, Europe, LatAm
- Live ECB rates via frankfurter.app
- $0.10 USDC per route — ~4 seconds settlement

- GET /api/health
- GET /api/rates
- POST /api/authorize
- POST /api/orchestrate
